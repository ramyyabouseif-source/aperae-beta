# Manual Validation Checklist

## Quick Reference Guide

### For Each Wine:

1. ✅ Open Wine-Searcher.com in browser
2. ✅ Search for wine using "Search Query" from spreadsheet
3. ✅ Find "Average Price" on results page
4. ✅ Record price in "Current Price" column
5. ✅ Fill in "Source" as "Wine-Searcher.com (manual)"
6. ✅ Fill in "Date" as today's date
7. ✅ (Optional) Check Wine.com for cross-validation
8. ✅ Mark as complete

---

## Step-by-Step Instructions

### Step 1: Open the Spreadsheet

1. Open `validationSpreadsheet.csv` in Excel or Google Sheets
2. You'll see columns you need to fill:
   - **Current Price (YOU FILL)** - The price you find
   - **Source (YOU FILL)** - Where you found it
   - **Date (YOU FILL)** - Today's date
   - **Notes (OPTIONAL)** - Any notes

### Step 2: Open Wine-Searcher

1. Go to: https://www.wine-searcher.com
2. Keep this tab open
3. This is legal manual browsing ✅

### Step 3: Look Up Each Wine

**For each wine in the spreadsheet:**

1. **Copy the Search Query** from the spreadsheet
   - Example: "Caymus Vineyards Cabernet Sauvignon 2020"

2. **Paste into Wine-Searcher search box**
   - Paste the search query
   - Press Enter or click Search

3. **Find the Average Price**
   - Look for "Average Price" or "Avg Price" on the results page
   - It's usually displayed prominently
   - If multiple vintages shown, find the specific vintage from spreadsheet

4. **Record the Price**
   - Copy the price (e.g., "$95" or "95")
   - Paste into "Current Price" column in spreadsheet
   - Remove "$" if present (just the number)

5. **Fill in Source**
   - Type: "Wine-Searcher.com (manual)"

6. **Fill in Date**
   - Type today's date (e.g., "2024-11-03")

7. **Optional: Cross-Validate**
   - Open Wine.com in another tab
   - Search for same wine
   - If price differs significantly, note in "Notes" column

### Step 4: If Wine Not Found

**If you can't find the wine:**

1. **Try without vintage**
   - Search just producer + wine name
   - Example: "Caymus Vineyards Cabernet Sauvignon"

2. **Try Wine.com**
   - Search there instead
   - Record if found

3. **If still not found:**
   - Type "NOT FOUND" in "Current Price" column
   - Add note: "Not found on Wine-Searcher or Wine.com"
   - This is okay! We'll exclude from analysis

## Tips

### Efficiency Tips

1. **Use Browser Shortcuts**
   - Alt+Tab to switch between browser and spreadsheet
   - Ctrl+C to copy, Ctrl+V to paste

2. **Batch Processing**
   - Do 10-20 wines per session
   - Take breaks
   - Focus = fewer errors

3. **Search Strategy**
   - Start with exact match from "Search Query"
   - If not found, try without vintage
   - If still not found, try just producer + wine name

### Quality Tips

1. **Take Your Time**
   - Don't rush
   - Verify you found the right wine
   - Check vintage matches

2. **Double-Check**
   - If price seems wrong, double-check
   - Look for "Average Price" not individual retailer prices

3. **Document Issues**
   - Note any uncertainties in "Notes" column
   - This helps with analysis later

## Questions?

**Q: What if I make a mistake?**  
A: No problem! Just fix it in the spreadsheet. We're looking for patterns, not perfection.

**Q: Do I need to be exact?**  
A: No. Round to nearest dollar. Focus on order of magnitude (e.g., $95 vs $100 is fine).

**Q: What if I can't find 20 wines?**  
A: That's okay! We only need 80-90 wines for 95% confidence. Missing 10-20 is fine.

**Q: Can someone else help?**  
A: Yes! Divide the list. Just make sure they follow the same process.
