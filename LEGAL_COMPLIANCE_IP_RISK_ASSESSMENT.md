## Detailed Findings

### Issue #1: App Name and Bundle Identifier Inconsistency

- **Category:** App Store Compliance / Branding

- **Status:** ❌ Missing Information

- **Severity:** CRITICAL

- **Description:** The app has been rebranded to "Aperae" throughout the codebase, but `app.json` still contains references to "PocketSomm":
  - `"name": "PocketSomm"` (line 3)
  - `"slug": "pocketsomm"` (line 4)
  - `"bundleIdentifier": "com.pocketsomm.app"` (iOS, line 13)
  - `"package": "com.pocketsomm.app"` (Android, line 31)
  - `"scheme": "pocketsomm"` (line 60)
  
  Additionally, README.md still references "PocketSomm" in the title and description.

- **Legal Risk:** 
  - App Store rejection due to name mismatch between app metadata and actual app name
  - User confusion and potential trademark issues
  - Inability to properly register trademark if bundle ID doesn't match brand
  - Potential rejection if app name in store doesn't match bundle identifier

- **Recommendation:**
  1. Update `app.json` to use "Aperae" consistently:
     - Change `"name"` to `"Aperae"`
     - Change `"slug"` to `"aperae"`
     - Change iOS `"bundleIdentifier"` to `"com.aperae.app"`
     - Change Android `"package"` to `"com.aperae.app"`
     - Change `"scheme"` to `"aperae"`
  2. Update README.md title and references
  3. Verify bundle identifier availability in Apple Developer and Google Play Console
  4. Update EAS project configuration if needed

- **Requires Attorney:** No (technical fix, but verify bundle ID availability)

### Issue #2: Image Asset Licensing Verification Required

- **Category:** Media Assets & Design

- **Status:** ⚠️ Needs Review

- **Severity:** CRITICAL

- **Description:** The app uses several image assets that require licensing verification:
  
  **Local Assets:**
  - `assets/images/pocketsomm-logo.jpg` - Logo file (proprietary, but file name inconsistent)
  - `assets/images/vineyard-hero-background.jpg` - Background image
  - `assets/images/wine-cellar-background.jpg` - Background image
  
  **External Assets:**
  - Multiple Unsplash images used in `SimplePremiumWineCard.tsx` and `PremiumWineCard.tsx` (12+ wine bottle/glass images from Unsplash)
  - Images loaded via Unsplash URLs (e.g., `https://images.unsplash.com/photo-1506377247377-2a5b3b417ebb`)

- **Legal Risk:**
  - **Unsplash License:** Unsplash images are free but require attribution under Unsplash License. Current implementation loads images via URL but may not include required attribution.
  - **Local Images:** No documentation found regarding source/licensing of `vineyard-hero-background.jpg` and `wine-cellar-background.jpg`. If these were generated by AI (Google Gemini as mentioned in previous discussions), need to verify commercial use rights.
  - **Logo:** If created via Canva, need to verify Canva license terms (free vs. Pro, commercial use rights).

- **Recommendation:**
  1. **For Unsplash Images:**
     - Verify all Unsplash images are properly attributed (Unsplash License requires attribution)
     - Consider adding attribution in app settings or about screen
     - Document which images are from Unsplash and their photographers
     - Review: https://unsplash.com/license
  
  2. **For Local Background Images:**
     - Document source of `vineyard-hero-background.jpg` and `wine-cellar-background.jpg`
     - If AI-generated (Google Gemini), verify Google's terms allow commercial use
     - If from stock photo service, verify license includes mobile app use
     - If original photography, document photographer and rights assignment
  
  3. **For Logo:**
     - Verify Canva license terms (if created via Canva)
     - Ensure commercial use rights are included
     - Document logo creation method and licensing
  
  4. **Create Asset Licensing Document:**
     - Maintain a document listing all assets, sources, and licenses
     - Include attribution requirements for each asset

- **Requires Attorney:** Yes (for complex licensing scenarios, especially AI-generated content)
