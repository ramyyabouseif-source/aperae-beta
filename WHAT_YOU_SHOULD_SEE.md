# What You Should See in My Cellar - Complete Guide

**Date:** December 15, 2025

---

## ✅ **VISIBLE NOW**

### **1. Main Screen:**
- ✅ **Title:** "My Cellar"
- ✅ **Statistics Dashboard:**
  - Total wines count
  - Want to Try count
  - Have Tried count
  - Favorites count
  - Average rating (if wines have ratings)
- ✅ **Filter Buttons:**
  - "All", "Favorites", "Want to Try", "Have Tried"

### **2. Wine Cards (Front View):**
- ✅ **Status Badge:** Red heart icon (defaults to "favorite")
- ✅ **User Rating:** Star rating if wine has been rated
- ✅ **All standard wine info:** Name, producer, vintage, etc.

---

## 🎯 **NEW: My Cellar Features on Card Back**

### **How to Access:**
1. **Tap a wine card** → Card expands (shows more content)
2. **Tap again** → Card **flips to back**
3. **Scroll down** → See **"My Cellar" section** (highlighted in red border)

### **"My Cellar" Section Contains:**

#### **1. Status Selector** ✅
- Three buttons: "Want to Try" | "Have Tried" | "Favorite"
- Current status highlighted in red
- **Tap to change status** → Saves automatically
- Badge on front updates immediately
- Stats dashboard refreshes

#### **2. Rating System** ✅
- **Wine Rating:** Tap stars (1-5) to rate the wine
- **Pairing Rating:** Tap stars (1-5) to rate the pairing
- **Saves automatically** when you tap a star
- Ratings appear on card front if set

#### **3. Notes** ✅
- **Wine Notes:** Text area for your tasting notes
- **Pairing Notes:** Text area for pairing experience
- **Auto-saves** when you finish typing (tap outside)
- Character counter (500 max)

#### **4. Tags** ✅
- **Add tags:** Type tag name and press Enter or tap +
- **Suggested tags:** "Special Occasions", "Date Night", etc.
- **Remove tags:** Tap X on any tag
- **Saves automatically**
